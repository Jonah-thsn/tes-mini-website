# TES Mini-Website

This repository contains the source code for the TES Mini-Website, a simple, static informational website built with vanilla HTML, CSS, and JavaScript. It serves as a demonstration or a landing page, showcasing core web technologies.

## Project Overview

The TES Mini-Website is designed to be lightweight and easily maintainable. It's a great example of a project that can be quickly deployed using static hosting solutions like Firebase.

## Technologies Used

*   **HTML**: For structuring the content.
*   **CSS**: For styling and layout.
*   **JavaScript**: For any client-side interactivity (if applicable).

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   You need to have `git` installed on your machine.

### Installation

1.  **Clone the repository**:
    ```bash
    git clone <REPO_URL>
    ```
    *Replace `<REPO_URL>` with the actual repository URL.*
2.  **Navigate to the project directory**:
    ```bash
    cd tes-mini-website
    ```

## Deployment

This website is deployed on Firebase Hosting. The deployment process is automated. Any new commits to the `main` branch are intended to trigger a new deployment.
